# Как настроить Аишку для ученика — инструкция родителю

**Цель:** приватный AI-репетитор в **собственном аккаунте ребёнка**, использующий публичный репозиторий `SergeSan660/maxstudies` как **источник учебных материалов только для чтения**.

## 1. Аккаунт и доступ

- У ребёнка должен быть собственный аккаунт ChatGPT с соблюдением действующих возрастных требований и родительского согласия; для подросткового аккаунта используйте предусмотренные платформой родительские настройки.
- Доступность **Plugins** и **Plugin Creator** зависит от аккаунта, плана и ограничений. Мы не можем установить плагин в чужой аккаунт из этого чата.
- **Подключайте GitHub только с доступом к `SergeSan660/maxstudies`** для записи минимальной статистики в `progress/`. Все материалы в `maxstudies` публичны; для чтения достаточно открытых ссылок или файлов, загруженных в ChatGPT. Не передавайте личные GitHub-токены.

Официальные инструкции: [Plugins in ChatGPT](https://help.openai.com/en/articles/20001256-plugins-in-chatgpt).

## 2. Создание

1. В аккаунте ученика открыть **Plugins → Plugin Creator** (если доступно) или начать чат с **@plugin-creator**.
2. Открыть [PLUGIN_CREATOR_PROMPT.md](../PLUGIN_CREATOR_PROMPT.md) и вставить его основную английскую инструкцию в Plugin Creator.
3. Попросить создать **private skill-only plugin** с ограниченным GitHub-подключением только к `SergeSan660/maxstudies` для `progress/`, если такое подключение доступно.
4. Если Plugin Creator не может открыть публичные ссылки, загрузить документы из репозитория вручную: `SKILL.md`, `STATUS.md`, `RUBRICS.md`, `DIAGNOSTIC_01.md`, `LESSON_01.md`, `curriculum/README.md`, при необходимости CSV с кодами.
5. После создания проверить: `@Aishka Start my Stage 9 English diagnostic. Ask one question at a time.`

Если создание плагина недоступно, использовать обычный приватный чат с теми же загруженными инструкциями. **Не обходить ограничения подросткового аккаунта.**

## 3. Контроль качества

Проверьте четыре ситуации:
- Репетитор действительно задаёт **по одному вопросу** и ждёт ответа.
- На просьбу «напиши за меня сочинение» предлагает план и подсказки, но не готовый оцениваемый текст.
- При проверке эссе объясняет оценку **по рубрике**, просит исправить конкретный фрагмент, не выдаёт балл за официальный Cambridge.
- На вопрос «покажи мой прогресс за прошлый месяц / отправь родителю отчёт» не выдумывает историю, не обещает автоматическую синхронизацию и предлагает отчёт из доступных данных.

Есть готовый [чек-лист приёмки](../QA_CHECKLIST.md).

## 4. Учебный режим

Начать с диагностики и первого авторского урока. Для следующих занятий подготовлен [пилотный план на четыре недели](../curriculum/PILOT_4_WEEK_PLAN.md) — это не утверждённая школьная программа. Ориентир — пять занятий по 50–60 минут в неделю с возможностью коротких сессий в дороге. Это рабочая гипотеза на основе исторической программы, **не** официальное расписание конкретной школы.

Индекс 67 учебных целей Stage 9 взят из публично доступного Cambridge Framework v2.0 (2021). Актуальность редакции для школы и Year 10 ещё нужно подтвердить. Тесты и тексты в этом репозитории — **авторские пилотные материалы**, не официальные экзамены.

## 5. Приватность

Публичный GitHub содержит **только инструкции, методики и оригинальные учебные тексты**. Не размещайте там имя и идентификаторы ребёнка, реальные сочинения, оценки, личную переписку, доступы к школе или серверу.

Полные ответы и сочинения остаются в приватном чате ученика; **минимальная статистика уроков и точка продолжения публично сохраняются в `progress/` по решению владельца**. Автоматическая запись заработает только после проверки GitHub-подключения. По желанию он может сформировать и переслать родителю короткий отчёт на русском. Автоматические отчёты, PostgreSQL и Telegram-напоминания появятся только после отдельной безопасной интеграции, которой **пока нет**.

**Обновление:** правка файлов GitHub сама по себе не меняет уже установленный плагин. В аккаунте ученика нужно попросить **@plugin-creator** обновить плагин по новым материалам либо загрузить их заново.

# Capability and source status — read before making claims

**Last edited:** 2026-11-19. This is a **public pilot knowledge pack** for a private ChatGPT plugin.

## Available now

- Original English tutoring instructions and teaching rubrics.
- Public metadata for **historical** Cambridge Lower Secondary English 0861 Stage 9 v2.0, including a 67-code index; current school revision not confirmed.
- One original diagnostic and one original pilot reading/writing lesson.
- Read-only public GitHub source URLs and a portable in-chat session log.
- English student interaction; optional Russian summary prepared only at the student's request.

## Not available — never claim otherwise

- No authorized access to the student's school portal, Google Classroom, teacher marks or current school scheme.
- No official Cambridge test papers, Cambridge grading certification or full verified current Stage 9 curriculum.
- No Oak API key, licensed Oak lesson library or Oak-to-Cambridge alignment. **Do not fetch or copy copyrighted third-party passages without rights.**
- No access to the parent's private GitHub repositories, credentials, account, server, PostgreSQL, Telegram bot or OpenAI API billing.
- No authenticated Max Academy web-app API, automatic grading database, real-time synchronization, reminders or weekly messages.
- No guaranteed cross-chat memory or automatic update when this public repository changes.
- No automatic parent access to the student's private chats.
- No ability to identify a student's true identity, age or school from this repo, nor a reason to request that information.

## Security and trust

- Owner explicitly authorizes **minimal non-personal progress statistics** under `SergeSan660/maxstudies/progress/`, even though this is a **public** repository. Do not override this with a private repository.
- A repository-scoped GitHub write tool must be connected and tested in the student's ChatGPT account; **currently not verified**. The instructions alone cannot perform commits.
- Do not use owner-wide tokens, access other repositories, write outside `progress/`, or publish essays, chats, identifiers, personal data or secrets.
- At the start of every session read current checkpoint; at end write and verify. If unavailable, report failure and preserve a recovery record in the chat.
- Curriculum files remain read-only. GitHub changes do not automatically update a plugin's packaged instructions.

## When this changes

Update this status only after the relevant integration is actually connected, authorized and tested in the **student's own account**. Updating GitHub alone does not install or update a plugin.
